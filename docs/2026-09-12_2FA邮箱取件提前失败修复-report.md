## 密码与 2FA 安全复核

- `_setup_password_with_driver` 先取历史快照，再记录 requested_at，然后触发重认证；旧码和旧消息 ID 筛选保留。仅真邮箱等待超时、同一有效挑战允许一次重发；网络错误不重发。
- 密码只在已提交新密码且观察到成功文案/可信 callback 后返回 ok，随后才持久化确认 checkpoint；取件失败没有密码成功结果。
- 补密码后丢弃旧注册 Token，同一浏览器 Session 精确匹配邮箱再 MFA；不切 Cookie、代理或 Profile。
- enroll 必须返回有效 secret/session_id；activate 必须 `success is True` 后才保存 Secret。后续 models 只读校验失败独立记录，不倒推激活失败。
- 邮件错误 message 仅组合异常类名与白名单 `stage/type/http_status`，不透传原始异常正文；既有 code 和 stage 维持兼容。
- 无真实密码重置、MFA 写入或新账号试跑，本轮现场动作仅为上述两个邮箱只读 GET。
