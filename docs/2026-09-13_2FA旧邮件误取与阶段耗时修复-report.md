## 密码与 2FA 安全复核

- 密码输入/点击不等于成功，`_setup_password_with_driver` 仍等待页面成功终态；只有成功后调用 `persist_confirmed_registration_password`。
- `expected_email` / `_assert_authenticated_account`、同窗 Cookie 与代理、补密码后刷新 Token 和激活前显式透传保持不变，新增日志不输出身份或凭据。
- 同一次 enrollment 的 Secret/session_id 保持配对；只有 activate `success is True` 才返回成功、写 Secret checkpoint。对 HTTP 400 新增回归验证不重复 enroll/activate。
- `_validate_2fa_token` 仍在已确认激活后独立执行；只读校验错误不抹去已确认的密码/TOTP，也不冒充激活失败。
