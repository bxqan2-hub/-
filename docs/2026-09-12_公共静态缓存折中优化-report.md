### Finding → Path → 修改

| Finding | 原有路径 | 修改 |
| --- | --- | --- |
| Fetch 订阅和 host gate 排除了真正大户 `chatgpt.com/cdn/assets/` | `RoxyTrafficOptimizer._install_fetch_cache`、`is_cacheable_request` | 使用同一 host→prefix 映射生成精确订阅和准入规则，增加该路径，不放开整个 ChatGPT 域 |
| immutable 是不符合实际源站响应的硬门槛 | `_cache_freshness_seconds`、`is_cacheable_response` | public + 正剩余 TTL 即可；immutable 可有可无，private/no-store/no-cache/Vary/状态头仍拒绝 |
| 仅十六进制 hash 漏掉真实构建名 | `is_cacheable_request` | 接受末尾 hex 8–64 位，或分隔后的 base36 8/16 位且含数字。未版本 settings/features/manifest 等名字与 Sentinel/challenge 文件仍排除 |
| Cookie 一律排除，把环境 Cookie 附带的公共文件也当作私有数据 | 请求门禁及现有响应门禁 | 只在合格静态路径允许 ambient Cookie 候选；Cookie 不入 key/metadata/replay。Authorization/Proxy-Authorization/Range/If-*/X-* 仍实时；Set-Cookie 响应仍整项不共享 |

| 399 秒配置过短 | 原有配置字段/帮助 | 运行值与默认值设为 86,400 秒；不新增开关、不关闭原始源站过期检查 |
