# 注册分轮定时扩展

## 范围

- 注册页新增“分轮定时”、等待秒数范围和计划状态/停止控件。
- 原 `/api/jobs` 默认路径仍调用 `submit_registration`；只有 `schedule_enabled=true` 才进入分轮调度。
- 分轮调度位于 `core/registration_service.py::submit_scheduled_registration`，每轮数量为并发数，等待范围使用 `random.uniform(delay_min, delay_max)`。
- 计划停止只阻止后续轮次，当前已提交任务继续走原有停止/终态逻辑。
